Status and roadmap. Update the checklist as work lands; keep `[[SPEC]]` in sync with

## Architecture

```
Browser (static/) --> Spring Boot (single jar)
                        ├─ auth/    signup, login, JWT issue/validate
                        ├─ habit/   CRUD + toggle, owner-scoped
                        ├─ streak/  pure streak math, no framework deps
                        ├─ log/     per-day completion records
                        └─ config/  security filter chain, health, error mapping
                        --> Postgres (prod) / H2 (tests)
```

Build: Gradle (`build.gradle`, wrapper checked in). Package: `bootJar` → single
executable jar, built inside a multi-stage Dockerfile.
